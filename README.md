# Smart Trash Journey

A static landing page for a Smart Trash product concept and user journey experience. The project is built as a single-file website using HTML and CSS, with a dark themed design and illustrated timeline that explains how waste sorting and recycling can work in practice.

## Overview

This project presents a branded "Smart Trash Journey" experience, showcasing:

- a product-style hero section
- a guided timeline of user steps
- waste sorting/bin education
- interactive visual storytelling through a single-page layout
- a dark modern aesthetic inspired by hand-drawn road maps and paper notes

## Project structure

- `index.html` — complete website markup, styles, and embedded assets in one file
- `LICENSE` — MIT license

## Preview locally

Because this is a static HTML page, you can open it directly in a browser:

1. Open `index.html` in your browser, or
2. Serve it locally from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

You can update the branding, text, colors, or layout directly in `index.html`.

Common areas to edit:

- hero title and messaging
- step/timeline content
- bin illustrations and labels
- color palette variables at the top of the stylesheet
